# Boot Image and Patched Boot Image for OnePlus 13R

## Overview
This repository contains the boot image and a patched boot image for the OnePlus 13R. These files are provided to help users root their device without downloading the entire ROM.

## Contents
- **Boot Image**: The original boot image extracted from the OnePlus 13R firmware.
- **Patched Boot Image**: A pre-patched boot image ready for rooting purposes.

## Version
- Firmware Version: **CPH2691_16.0.0.205(EX01)**

## Usage Instructions
1. Download the required boot image or patched boot image from this repository.
2. Use a tool like `fastboot` or `ADB` to flash the image onto your device.
3. For the patched boot image, ensure that you have an appropriate custom recovery or follow the rooting instructions provided for the OnePlus 13R.
